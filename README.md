# RightsRadar UK

Independent UK legal-information website providing plain-English rights guides with jurisdiction labels and links to official sources.

## Current scope
- Scotland police and criminal-court rights
- New & Changed Laws feed
- Privacy, terms and legal-information disclaimer

## Deployment
This repository is intended to deploy directly to Vercel from the `main` branch.

RightsRadar UK provides general legal information, not personalised legal advice.
